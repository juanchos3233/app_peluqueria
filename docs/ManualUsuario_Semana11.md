# Manual de Usuario — AppSalon (Semana 11)

## 1. Acceso
- Ir a la URL de inicio (por defecto `http://127.0.0.1:8000`).
- Puedes **registrarte** o iniciar sesión con las credenciales de prueba.

## 2. Ver Servicios
- En la portada se muestra el **catálogo de servicios** con precios y duración.

## 3. Agendar Cita
1. Inicia sesión.
2. En el menú, selecciona **“Agendar Cita”**.
3. Escoge **fecha**, **hora** y **uno o más servicios**.
4. Envía el formulario. Verás un mensaje de éxito con el **total**.

## 4. Panel de Administración
- Requiere iniciar sesión como **admin**.
- Desde el menú, ve a **Admin** o **Servicios (Admin)**.
- Podrás **crear/editar/eliminar** servicios y ver **citas del día**.

## 5. Cuentas de prueba
- Admin: `admin@appsalon.test` / `password`
- Cliente: `cliente@appsalon.test` / `password`

> Para la evaluación de la Semana 11, se cubren: BD, autenticación, sesiones, validaciones, CRUD de servicios, vistas responsive básicas.
